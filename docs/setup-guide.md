- Create a "Trading AI" folder in your notes app
- Set up a template for saving AI outputs

## How to Use Each Prompt

### The 3-Step Process
1. **Copy** the prompt text
2. **Customize** — replace all `[BRACKETED_VARIABLES]` with your specific data
3. **Execute** — paste into your AI tool and review the output

### Example: Using Prompt #5 (Company Deep-Dive)
```
STEP 1: Copy the prompt
STEP 2: Replace variables:
  [SECTOR] → "cloud infrastructure"
  [TICKER/COMPANY] → "NET / Cloudflare"
STEP 3: Paste and review. Follow up with specific questions.
```

### Getting Better Outputs
- **Be specific with data:** Paste actual financial metrics, not just ticker symbols
- **Set the role:** Each prompt starts with "Act as..." — keep this, it matters
- **Iterate:** Ask follow-ups like "Dig deeper into point 3" or "What am I missing?"
- **Chain prompts:** Use output from Prompt #5 as input to Prompt #31 (stress test)

## Troubleshooting

### "The AI output is too generic"
→ Add more specific data to your input. Paste actual numbers, not just descriptions.

### "The AI is hallucinating data"
→ AI can make up numbers. Always verify key data points with your own research. Use Perplexity for real-time data.

### "I'm not sure which prompt to use"
→ Use the Quick Reference Card. Match your situation to the category table.

### "The output is too long"
→ Add "Keep it under 500 words" or "Give me bullet points only" to any prompt.

## Pro Tips from Experienced Users

1. **Start a new chat** for each analysis to avoid context contamination
2. **Use system prompts** if your tool supports them — set "You are a senior equity analyst at a hedge fund" as your default
3. **Save everything** — your AI outputs become valuable data for Prompt #22 (edge identification)
4. **Temperature settings** — set to 0.3-0.5 for consistent, analytical outputs
5. **Combine with your journal** — paste AI analysis directly into your trading journal entries
