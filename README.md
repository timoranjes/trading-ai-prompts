## How It Works

1. **Copy** any prompt from the library
2. **Replace** `[bracketed variables]` with your specific data
3. **Paste** into ChatGPT, Claude, or Gemini
4. **Iterate** with follow-up questions for deeper analysis
5. **Save** outputs to your trading journal
